# Documentation de référence du Korg Z3

Source : https://gr300.com/korgz3.htm (téléchargé le 26/10/2026).

| Fichier | Contenu |
|---|---|
| `Korg_Z3_Manual.pdf` | Manuel utilisateur (scan) ; la table SysEx des paramètres de son est vers les pages 33-36 |
| `manuel_ocr.txt` | Texte du manuel, OCR macOS Vision (approximatif sur les tableaux) |
| `Korg_Z3_Preset_Sound_Settings.pdf` | Les 128 sons d'usine, fiches éditées avec MOTU Unisyn |
| `fiches_unisyn.txt` | Texte extrait de ces fiches |
| `Errata_Sheet_Korg_Z3.pdf` | Errata du manuel |

Le manuel ne donne que les noms et les plages ; les libellés Unisyn (Int Ratio,
Fine Ratio, Inharm Mult, Rate K.Scl, Velo Sens, Kybd Trak) éclairent le sens des
paramètres (puce Yamaha YM2414, comme le TX81Z).
